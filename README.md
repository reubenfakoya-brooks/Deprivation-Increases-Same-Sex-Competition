OTree download and installation instructions can be found on oTree Studio Hub: https://otree.readthedocs.io/en/latest/studio.html

Code was produced on their classic version and  Python 3.7 or newer is required on the operating system.

To automatically run oTree Zip Folders, the instructions are as follows:

Open your command prompt in your downloads folder and run otree zipserver.

Open your browser to http://localhost:8000/ and play your game.

To stop the server, press Control + C at your command line.
